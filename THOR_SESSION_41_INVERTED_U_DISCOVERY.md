## Theoretical Framework: The Cognitive Sweet Spot

### Hypothesis: Yerkes-Dodson-Like Wake Activation

**Yerkes-Dodson Law** (1908): Performance follows inverted-U curve with arousal
- Too little arousal → Insufficient engagement
- Optimal arousal → Peak performance
- Too much arousal → Cognitive overwhelm

**SAGE analog**:
- **Trivial queries** (Level 1): No challenge → No need for wake (routine rest processing)
- **Moderate queries** (Level 3): Optimal challenge → Maximum wake (preparatory activation)
- **Demanding queries** (Level 5): Excessive difficulty → System recognizes futility → Reduced wake

### Three-Zone Model

**Zone 1: Under-arousal** (Levels 1-2, wake 12.5-25%)
- Query demands below cognitive engagement threshold
- System processes in rest mode (routine)
- Wake activation minimal

**Zone 2: Optimal arousal** (Level 3, wake 60%)
- Query demands match cognitive capacity
- System activates wake for enhanced processing
- Maximum preparatory investment
- "This is worth preparing for"

**Zone 3: Over-arousal** (Levels 4-5, wake 40-25%)
- Query demands exceed practical capacity
- System recognizes diminishing returns
- Wake activation reduces despite difficulty
- "Preparation won't help enough"

## Why This Makes Sense

### Metabolic Efficiency Argument

Wake state is **metabolically expensive** (ATP cost). System should only activate wake when:
1. Query is challenging enough to benefit from preparation
2. Query is tractable enough that preparation will help

**Level 3 (moderate)**: Both conditions met → maximum wake
**Level 5 (demanding)**: Condition 2 fails → reduced wake (why waste ATP on impossible task?)

### Metacognitive Awareness

The inverted-U suggests SAGE has **implicit difficulty assessment**:
- Can distinguish "challenging but tractable" from "overwhelming"
- Allocates metabolic resources strategically
- Shows adaptive resource management

This is evidence of **metacognitive competence** - knowing when effort will be productive.
