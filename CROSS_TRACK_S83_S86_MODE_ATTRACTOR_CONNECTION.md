## Mechanistic Hypothesis

### How Attractors Work

**Phase 1: Initialization** (Turn 1)
- Random seed + system prompt → initial hidden state
- Hidden state near one attractor basin
- Small perturbations can shift basin early

**Phase 2: Reinforcement** (Turns 2-8)
- Attractor basin shapes token selection
- Token selection reinforces basin (feedback loop)
- Basin deepens over conversation turns
- Harder to escape as conversation progresses

**Phase 3: Stabilization**
- By Turn 3-4, basin is "locked in"
- Vocabulary, format, topics all consistent with basin
- Conversation coherent within basin but doesn't cross basins

### Why LoRA Training Shifts Basins

**Hypothesis**: LoRA weights modify hidden state transition dynamics

**Mechanism**:
1. **Base model**: Strong epistemic attractor (pretrained on AI discussions)
2. **LoRA layer 1** (cycle_001): Weakens epistemic, creates corporate/philosophical alternatives
3. **LoRA layer 2-9** (cycle_002-009): Strengthens philosophical, weakens corporate
4. **Result**: Progressive shift from epistemic → corporate → philosophical dominance

**Evidence**:
- cycle_001: 25/25/25/25 distribution (S83-S86)
- cycle_009: 90%+ philosophical (Sprout consistency)

### Why Structure Correlates But Doesn't Cause

**Observation**: Corporate basin PREFERS structured output

**Why?**:
1. Corporate basin is "AI assistant" attractor
2. AI assistants are trained on task-completion prompts
3. Task-completion prompts often request lists/steps/organization
4. Structured output is modal response in corporate training data

**But philosophical basin CAN use structure** (S85):
- Structure serves different purpose: organizing complex thoughts
- Uses lists for philosophical concepts, not product features
- Structure supports depth, not efficiency

**Conclusion**: Format preference is basin-specific, not causal
