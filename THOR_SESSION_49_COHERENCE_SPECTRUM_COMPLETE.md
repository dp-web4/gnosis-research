## Experimental Limitations

### 1. Simulation-Based

**Issue**: Used simulated responses, not real SAGE outputs.

**Impact**:
- RDS patterns likely accurate (controlled variability)
- SIM patterns less reliable (artificial state correlations)
- Cannot validate absolute RDS values

**Mitigation**: Follow-up with real SAGE raising data analysis (Session #50 candidate).

### 2. Coarse Sampling

**Issue**: ΔC = 0.1 resolution may miss fine structure.

**Impact**: True peak could be at C = 0.48 or C = 0.52, not exactly 0.50.

**Mitigation**: Session #47 used finer sampling (C ∈ {0.15, 0.35, 0.50, 0.65, 0.75}) and found peak at 0.50 - consistent with this session.

### 3. Small Sample Size

**Issue**: N = 15 per level insufficient for robust statistics.

**Impact**: SIM shows high variance, obscures tradeoff pattern.

**Mitigation**: Real SAGE data has N = 50+ sessions per instance, sufficient for robust analysis.

### 4. Metric Limitations

**Issue**: RDS is simple lexical diversity, not true semantic flexibility.

**Impact**: May underestimate flexibility in structured responses.

**Mitigation**: Future work should use:
- Sentence-transformer embeddings for semantic similarity
- Multiple flexibility metrics (structural, conceptual, stylistic)
- Human expert ratings of creativity/flexibility
