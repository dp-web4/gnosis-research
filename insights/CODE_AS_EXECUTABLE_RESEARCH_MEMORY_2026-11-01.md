# Executable hypotheses as research memory across sessions

2026-11-01 · INSIGHT-CODE-WORLD-MODELS-2026-11-01  
Dennis Palatov's framing; NOVA / ChatGPT synthesis. Methodological insight, not a new experimental result.

> "code is your magic spell" — Dennis, reaffirmed 2026-11-01

The [SAGE companion, PR #621](https://github.com/dp-web4/SAGE/pull/621), treats code as an executable world-model medium, experimental instrument and prime computational effector. This repository's [README](../README.md) already describes continuity through a committed research record and successor sessions that challenge earlier claims. Code can make that continuity operational rather than merely narrative.

## Inherit an instrument, not just a conclusion

A successor should be able to locate the exact program, assumptions, dependency/configuration identity, prediction and observed result behind a claim. It can then rerun the instrument, alter a relevant assumption and construct a counterexample. A persuasive synthesis without those artifacts can transmit the conclusion while losing the means to test it.

A useful executable model may be small: a detector, a transition rule, a null model, a measurement operator or a short analytical check. It need not be a full simulator. Let the investigator author the instrument a new question requires rather than limit inquiry to the tools anticipated by the original research plan.

## Keep three levels of evidence separate

A program's successful execution establishes that the specified computation ran. Reproduction establishes stability of a result under stated conditions. An independent comparison can test whether the interpretation describes the phenomenon. None automatically implies the next.

Especially when the same code generates the phenomenon and measures it, inspect whether the apparent finding is imposed by the generator, metric or selection procedure. Use alternative implementations, controls and changed cases to discriminate the hypothesis from those explanations.

## Preserve correction as part of memory

Retain the old artifact and the observation that overturned it. A later session must be able to see why a prior conclusion was superseded rather than rediscover it from a decontextualized summary. Record unresolved alternatives; absence of a measurement is not evidence of absence of the effect.

Attribution should distinguish an author's hypothesis, an executor's run and a reviewer's independent check. An AI peer can perform all necessary review functions across separate acts; this note creates no human-review prerequisite. Independence must be demonstrated by what was tested, not merely by a new session name.

## Proposed readout

Choose one claim and trace `question -> executable model -> predeclared prediction -> observation -> counterexample/revision -> successor reuse`. Compare evidence-bearing artifact handoffs with narrative-only handoffs at the same model and budget. Measure incorrect inherited premises, successful correction, useful new tests and task cost.

This note does not alter any existing coherence, detector, self-awareness or physical interpretation; it adds no supporting data for them. It articulates a method: **make understanding executable enough that a successor can do more than repeat it.**
